# A6: the key allowlist in edit mode, and the save chords inside the text editor

**Status: PASS** (3 of 3 runs; see Runs). Branch `spike/a-host`, Windows 11, Node 24, Playwright 1.63.0
headless Chromium shell, engine 0.18.0-1118751.

Plan §8.2 A6 (with revision 3.1 open item 1): *the key allowlist (§2.3.3) in edit mode: every
"Everything else" key does nothing. Also with the text editor focused: Ctrl+S, Cmd+S and Ctrl+Shift+S do
nothing. Pass: 0 downloads, 0 dialogs, 0 element changes.*

## Open item 1, verified in the dist first

- The textarea's own `editable.onkeydown` (index.js 25367-25409) has
  `else if (actionSaveToActiveFile.keyTest(event)) { event.preventDefault(); handleSubmit();
  app.actionManager.executeAction(actionSaveToActiveFile); }` (25388-25391).
- `actionSaveToActiveFile.keyTest` is `event.key === "s" && event[CTRL_OR_CMD] && !event.shiftKey`
  (11606); `CTRL_OR_CMD` is `metaKey` on macOS and `ctrlKey` elsewhere, decided once at load from
  `navigator.platform` (common dist/dev/index.js 2242, 2391).
- `ActionManager.executeAction` (23095-23106) never calls the action's `predicate`, so
  `canvasActions.saveToActiveFile: false` (whose predicate is at 11554-11556) does not stop it. `perform`
  (11557-11605) exports the whole scene and calls `saveAsJSON` with the (null) file handle, which in
  Chromium opens the File System Access save picker (`browser-fs-access`; scaffold finding).
- Ctrl+Shift+S inside the textarea: not handled by the textarea (the keyTest needs `!shiftKey`) and the
  container's `onKeyDown` returns early for a writable target (44005-44011), so it is inert there; it is
  blocked anyway.
- Confirmed by the CONTROL runs below (allowlist off): Ctrl+S on Windows and Cmd+S on macOS (emulated with
  `navigator.platform = 'MacIntel'` before load) close the editor and call `showSaveFilePicker` once.

Allowlist decisions beyond the plan's table (documented in `keymap.ts`):
- A blocked key with Ctrl, Cmd or Alt is also `preventDefault`ed, except browser chords (reload, tabs,
  windows, address bar, devtools): stopping propagation alone would let the BROWSER act on Ctrl+S (Save
  page), Ctrl+P (Print), Ctrl+O (Open file) or Alt+Left (Back). Unmodified blocked keys are prevented
  too, except F1-F12.
- Inside the text editor with a granted lease every key is delegated except Ctrl/Cmd+S and
  Ctrl/Cmd+Shift+S (blocked, prevented).

## What "does nothing" means here

Scene: 3 rectangles, an ellipse, an arrow, a line, a free text and a note with a label. Each key is
pressed twice: with ONE shape selected (for Tab conversion and the flowchart keys) and with EVERYTHING
selected (align, distribute, flip, styles). Per press, after two animation frames + 150 ms: no element's
`(version, versionNonce)` changed and no element appeared; none of 30 appState fields changed (tool and its lock,
dialog, popup, menu, sidebar, context menu, toast, zen/grid/snap/stats/view modes, theme, pen mode,
export flags, hyperlink popup, text/linear/group/crop/frame editing, file handle, selection, zoom,
scroll, current font size and colours); no download, browser dialog, file chooser, popup, File System
Access picker call (`showSaveFilePicker`, `showOpenFilePicker`, `showDirectoryPicker`, instrumented) or
`navigator.clipboard.write`/`writeText` call (instrumented); the page did not navigate.

Keys (70): the plan's "Everything else" row (33: Ctrl+S, Ctrl+Shift+S, Ctrl+O, Alt+Shift+C, Ctrl+Shift+E,
Ctrl+/, Ctrl+P, Ctrl+Backspace, Ctrl+Arrow x4, Alt+Arrow x4, G, S, I, Shift+F, Shift+S, Shift+G, ?, digits
0-9) and 37 more Excalidraw shortcuts that are neither delegated nor Lobby-owned (from the `keyTest`s in
dist/dev/index.js and the TOOLS letter/numeric keys at 9934-10025): D, A, X, B, Q, W, Shift+X (autoshape),
Ctrl+Shift+P, Alt+Shift+D, Ctrl+Alt+C, Ctrl+Alt+V, Ctrl+Shift+Arrow x4, Alt+H, Alt+V, Shift+H, Shift+V,
Ctrl+X, Ctrl+', Alt+Z, Alt+S, Alt+/, Ctrl+K, Alt+R, Shift+1/2/3/0, Shift+=, Shift+-, Ctrl+Shift+,
Ctrl+Shift+., Ctrl+Enter, Tab, Shift+Tab.

**Control (allowlist off, `?allowlist=off`)**: the same 140 presses reach Excalidraw. A key that acted
gets a fresh page for the next key.

Keys that did nothing even without the allowlist: Ctrl+S outside the editor (the predicate needs a file
handle), Ctrl+O (`canvasActions.loadScene: false` filters it in `handleKeyDown`, 23060-23062),
Ctrl+/ and Ctrl+Shift+P (the command palette is not mounted with `ui={false}`), Ctrl+Backspace, I, W,
1 (selection tool), 9 (image: `tools.image: false`), Alt+Shift+D (toggleTheme predicate false),
Ctrl+Alt+V, Shift+S, Shift+G, Shift+0, Ctrl+Enter, Tab (see below).

**Finding: Tab changes state the probe cannot see.** With one shape selected, Tab (Excalidraw 43960-43977)
sets `convertElementTypePopupAtom` (a jotai atom, not appState; its panel is not rendered with
`ui={false}`), so the Tab press looked like "nothing"; the next key, Shift+Tab, then converted the shape
in place (`convertElementTypes`). With the allowlist, Tab is the "browser" class (propagation stopped,
default kept: the focus leaves the canvas), and Shift+Tab never converts.

## Lobby's Ctrl+A

Scene: a 2-rectangle group, a locked rectangle, a rectangle marked hidden (mind-map collapse), a note
with a label. Lobby's Ctrl+A selects `g1a`, `g1b`, the note (not its label, not the locked one, not the
hidden one) and the group `grp`, with 0 element changes; Excalidraw's own select-all (control) also
takes the hidden element. Excalidraw expands selected groups to every live member, locked ones and
labels included, and drops groups with fewer than 2 members (element dist/dev/index.js 12228-12290);
`selectAll.ts` mirrors that and never adds a hidden member.

## Deviations from the plan

- The plan's row says "stopPropagation"; the spike also `preventDefault`s blocked chords (see above).
  Proposed addition to §2.3.3: *"Blocked keys with Ctrl, Cmd or Alt are also `preventDefault`ed, except
  browser chords (reload, tabs, windows, address bar, devtools), so the browser does not save, print,
  open a file or go back."*
- Scaffold correction applied: "0 downloads" also counts File System Access picker calls; the control
  shows why (Ctrl+Shift+S produces a picker call and 0 downloads).
