## What `count()` means

`PushLog.count()` is the number of PUSHES, and a doc-only push counts. `ops()` flattens their ops.
`byElement(id)` returns the ops naming `id`. A page that reloads starts a new push log in its engine
core. The recorder keeps what it last read from the old page and adds the new page's pushes, so a push
made between the last read and the reload is not seen. D5 and D6 specs that reload a receiver should
read the log right before the reload.
