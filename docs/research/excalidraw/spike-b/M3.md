## Open problems, per owner

**O2 (web engine)**
- **Data loss: a local edit or create that a server frame overtakes is lost** (O3's and O5's finding,
  reproduced here). `CanvasPort.transact` and user edits install the scene with `updateScene`; the core
  learns of it only from Excalidraw's next `onChange`, after React's commit. A `changes` or `ack` frame
  handled in between calls `applyScene`, which builds the element array from `this.currentOrder` (the
  scene as the core last scanned it, `sync/core/engine.ts` `applyScene`) and installs it, so the unscanned
  edit is overwritten, nothing is pushed, and the tab shows "Saved". On the integrated tree it loses 5 of
  400 facade creates, 2 of 40 edits under a 50 Hz remote writer, and 3 of 200 mood-board images, and it
  plausibly explains L10 6's missing rotation. B11 and every hash check cannot see it (all maps stay equal).
  The direction O3 and O5 suggest: scan the live scene before any server-driven apply (`onChanges`,
  `onAckMessage`, `afterWelcome`), or build the applied array from `scene.read()`. Mind that `scan` itself
  calls `applyScene` for resets. **Acceptance:** `b7-probe-lost-create` and `b9-probe-lost-edit` pass 3/3,
  B7 passes 3/3, and L10 6 passes 20/20 in both orders and both modes. Blocks the report (§8.6.8).
- **B11: one unexplained divergence** (1 of 6 valid owner runs: browser A held a note with a different
  index, version, versionNonce and `updated` while Saved). Not seen in this pass. O3's `support/diverge.ts`
  records the detail if it recurs; V1 should try to reproduce it.
- **Performance, with O5:** `CanvasPort.bounds` (`port-impl.ts`) does a linear find and builds a new Map of
  every element per call; the overlay layers and O5's image card layer call it per image on every change
  and viewport event. The heavy board pans at 4-7 fps and B9's A→B p95 is 1.5-1.9 s. The fps and visibility
  gates cannot pass until this is fixed.
- **The CR:** O2's explicit OK for `b5689e0`, and the page's "Preparing this board…" state on `PREPARING`
  and a clear message on `CONVERSION_FAILED`.
