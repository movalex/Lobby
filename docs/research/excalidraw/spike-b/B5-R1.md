# B5 R1: read-only enforced on the server (O1)

**Check** (docs/EXCALIDRAW-MIGRATION.md §8.3 B5): a viewer's raw socket (its own ticket) sends a create, a
patch, a delete, a `doc` write, a `lease.acquire` and a presence message with a `drag` of 5 live ids.
Pass: `READ_ONLY` per op and a lease deny; the socket stays open; the snapshot is unchanged; the editor sees
no element change and no drag preview. Presence flows for every read-only role: the viewer's, a
commenter's and a limited guest's cursors, moved with no tool selected, appear on the editor's screen
within 200 ms p95.
