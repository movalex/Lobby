## Decisions

- **A2 `anonymous` = `voteOpen`.** Lobby's dot votes have no named-ballot mode: every ballot stays secret
  until the reveal (PRF-07), so an open vote is always anonymous. The field is kept so a later named mode
  needs no contract change.
- **The api pushes A2 fire-and-forget after commit** (vote start, close, reveal, extend) and at a timed
  vote's end (an in-process timer; a vote with an end time ends without a request). A tldraw sync answers
  404 (logged at debug). After an api restart the end timer is gone: sync's pull at room open, and a
  re-pull the room may add, are the backstop (O1).
- **Vote targets are `shape:<element id>`** through the vote contract's `^shape:[A-Za-z0-9_-]{1,100}$`,
  narrower than the element id pattern (`.` and `:` allowed). New elements (nanoids) always fit; a
  converted element whose id carries `.` (`<id>.t` labels, `<id>.o` outlines) cannot take a vote. Labels
  vote for their container anyway; outlines are lines (ineligible). No finding for R2; noted for wave 2.
